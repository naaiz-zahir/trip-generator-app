Data & Sync

Changes are always saved in this browser. To share them with everyone else, connect a GitHub token so the app can commit database.json back to the repository.

Use a fine-grained personal access token limited to this one repository, with Contents: Read and write. It is stored in this browser only — anyone who can use this device can read it, so do not set it up on a shared or public machine.
Add, rename or delete entries directly, then save.
